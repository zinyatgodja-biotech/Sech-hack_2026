# Деталь "Каретка"

## Вставляется в пазы стойки, способна перемещаться вдоль стойки при помощи шагового двигателя и резьбового вала. На нее крепится гайка М4. Используется для приведения в движение поршень.

---

# Деталь "Стойка"

## Сверху закрепляется шаговый двигатель, в ней находится резьбовой вал и каретка. Внизу крепится поршень, который приводится в движение и продавливает мембрану
