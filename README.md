# Sech-hack_2026: Разработка стенда для тестирования микрофлюидных картриджей | Кейс от ООО Рапид Био

Репозиторий содержит код локального десктопного приложения на Python для управления плунжером, воздействующим на мембрану микрофлюидного картриджа, и контроля положения капли в капилляре с помощью USB-камеры.

Все основные функции управления и мониторинга доступны в едином пользовательском интерфейсе.

Система построена на взаимодействии компьютера и микроконтроллера Arduino. Компьютер отвечает за расчёт целевого перемещения плунжера, обработку видеопотока, калибровку системы и ведение журнала работы. Arduino выполняет команды управления приводом, обеспечивает ручное управление и контролирует соблюдение заданных безопасных границ перемещения.
