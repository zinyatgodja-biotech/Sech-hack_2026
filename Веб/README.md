## Запуск на Windows
1. Установите Python
2. Откройте терминал в папке проекта.
3. Выполните:
py -m pip install -r requirements.txt
py app.py
4. Откройте в браузере **http://127.0.0.1:5000**.
5. Для остановки сервера нажмите **Ctrl+C** в терминале.

## Что за что отвечает
- `app.py` — команды, расчёты, состояние виртуального стенда и API.
- `templates/index.html` — блоки, поля и кнопки интерфейса.
- `static/style.css` — внешний вид интерфейса.
- `static/app.js` — отправка команд на Python и отображение результатов.
- `program.json` — создаётся при нажатии «Сохранить». (я уже насоздавал пока тыкал)
